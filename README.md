# 今って何年？

昭和・平成・令和と西暦を相互変換する、小さな静的サイトです。

## 使い方

`index.html` をブラウザーで開くだけで動作します。ビルド、パッケージのインストール、API、外部フォントは不要です。公開時は `index.html`、`style.css`、`calendar.js`、`app.js` を同じディレクトリに配置してください。

- 日本時間の今日と今年を表示。表示中は1分ごと、タブ復帰時にも更新。
- 入力と同時に変換。全角数字、和暦の「元」に対応。
- 西暦1926〜9999年、昭和1〜64年、平成1〜31年、令和1〜7981年に対応。
- 改元年は両元号と該当期間を表示。昭和元年は12月25日から。
- 未来の令和年は、令和が続くという仮定で計算。
- 通信、解析タグ、Cookie、入力の保存はありません。

## 検証

Node.jsの標準機能だけで実行できます。

```sh
node --test calendar.test.cjs
```

元号境界、全対応年の往復変換、不正入力、日本時間の年越しを確認します。
